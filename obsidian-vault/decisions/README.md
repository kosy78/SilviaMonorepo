# Decizii

Acest director conține deciziile materiale de produs, conținut, tehnologie și
conformitate.

Fiecare decizie trebuie să precizeze data, starea, contextul, opțiunile
analizate, decizia și consecințele. O decizie nouă care înlocuiește una
existentă trebuie să facă legătura către înregistrarea anterioară.
